GitHub Pages: загрузите файлы в корень репозитория. Settings > Pages > Deploy from a branch > main / root. Google Cloud Console: включите Google Sheets API, настройте OAuth consent (External, Testing, добавьте свой Gmail в Test users), создайте OAuth Client ID типа Web application, Authorized JavaScript origins: https://ВАШ-ЛОГИН.github.io (без пути). Вставьте Client ID в config.js. Не публикуйте client secret. Таблицу оставьте приватной. Откройте сайт, нажмите Войти через Google. На iPhone добавьте на экран Домой. При истечении токена повторите вход. Не редактируйте одновременно в старом и новом приложении: проверка версий не атомарна. Приложение не проверено с реальной OAuth конфигурацией.
